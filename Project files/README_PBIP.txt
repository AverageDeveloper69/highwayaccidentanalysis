Highway Accident Analysis Power BI Project

Open HighwayAccidentAnalysis.pbip with Power BI Desktop.
Keep these three items together in the same directory:
- HighwayAccidentAnalysis.pbip
- HighwayAccidentAnalysis.Report/
- HighwayAccidentAnalysis.SemanticModel/

The data tables are embedded in the semantic model's Power Query definitions.
The PBIP file is a project pointer; it is not a self-contained single-file
report. To transfer the project, send the ZIP bundle or the full directory.

The report has three pages: National Overview, State Hotspots, and Severity &
Road Context. It includes fixed 2022 KPI cards, annual trend charts, an Azure
Maps bubble map, a descending top-10 state ranking, a multi-state trend chart,
and 2022 NH vs other-roads composition charts. State NH coverage is limited to
the ten states ranked highest in 2022; counts are not exposure-adjusted risk
rates. Azure Maps needs internet access and may be disabled by an organization.
